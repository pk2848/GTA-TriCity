# GTA-TriCity vehicle assets

The player garage loads these GLB files on demand:

- `pagani-zonda-cinque.glb`
- `1970-dodge-charger-rt.glb`
- `2015-dodge-challenger-rt.glb`

Place the files in this folder by extracting the matching vehicle asset pack at the repository root. The app has a procedural fallback car when a GLB is missing.
